# ALX Interview

A collection of technical interview practice problems and algorithmic challenges completed as part of the ALX Software Engineering curriculum. This repository focuses on strengthening problem-solving skills, data structures, algorithms, and coding interview preparation.

## Overview

The ALX Interview repository contains solutions to common technical interview questions that emphasize writing efficient, optimized, and clean code. Each project explores a different computer science concept commonly assessed during software engineering interviews.

## Objectives

- Practice algorithmic problem solving
- Improve time and space complexity analysis
- Strengthen data structure knowledge
- Prepare for technical coding interviews
- Write clean, maintainable, and optimized code

## Topics Covered

Depending on the project, topics may include:

- Arrays and Strings
- Linked Lists
- Stacks and Queues
- Trees and Graphs
- Hash Tables
- Recursion
- Dynamic Programming
- Greedy Algorithms
- Backtracking
- Searching Algorithms
- Sorting Algorithms
- Bit Manipulation
- Matrix Operations
- Binary Trees
- Graph Traversal

## Requirements

- Ubuntu 20.04 LTS or later
- Python 3.x
- GCC (for C projects)
- Git

## Installation

Clone the repository:

```bash
git clone https://github.com/triggerAustin/alx-interview.git
```

Navigate into the project:

```bash
cd alx-interview
```

## Running Solutions

Example for Python projects:

```bash
python3 main.py
```

Example for C projects:

```bash
gcc -Wall -Werror -Wextra -pedantic *.c -o program
./program
```
